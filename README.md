# Wildberries Parser (Test Task)

Проект представляет собой парсер каталога товаров сайта `wildberries.ru`, реализованный в рамках тестового задания.

Парсер собирает данные по поисковому запросу **«пальто из натуральной шерсти»**, сохраняет их в базу данных и может быть использован для последующего экспорта в формат XLSX.

---

## 📋 Описание задания

*   **Сайт:** [https://www.wildberries.ru](https://www.wildberries.ru)
*   **Поисковый запрос:** `пальто из натуральной шерсти`
*   **Формат результата:** XLSX

### Список собираемых данных:
1.  Ссылка на товар
2.  Артикул
3.  Название товара
4.  Цена
5.  Описание
6.  Ссылки на изображения (через запятую)
7.  Все характеристики товара с сохранением структуры
8.  Название продавца
9.  Ссылка на продавца
10. Размеры товара (через запятую)
11. Остатки по товару (число)
12. Рейтинг
13. Количество отзывов

---

## ⚙️ Логика работы парсера

Парсер реализован в два этапа, что позволяет:
*   Избежать повторного парсинга одних и тех же товаров.
*   Контролировать прогресс обработки.
*   Легко масштабировать сбор данных.

### 1. Парсинг ссылок на товары
На первом этапе происходит сбор ссылок на товары из поисковой выдачи Wildberries.

**Алгоритм:**
1.  С помощью **Selenium** загружается страница поиска.
2.  HTML страницы передаётся в **BeautifulSoup**.
3.  Из карточек товаров извлекаются ссылки на страницы товаров.
4.  Все ссылки сохраняются в таблицу `urls` базы данных.
5.  Для каждой ссылки устанавливается флаг `is_parsed = False`.

**Файл:** `parse_items_url.py`

**Используемые компоненты:**
*   `PageLoader` — загрузка страницы
*   `DataFinder` — поиск HTML-блоков
*   `DataExtractor` — извлечение ссылок
*   `DBManager` — сохранение ссылок в БД

### 2. Парсинг данных о товаре
На втором этапе происходит детальный парсинг каждого товара по ранее сохранённым ссылкам.

**Алгоритм:**
1.  Из БД выбираются все ссылки с `is_parsed = False`.
2.  Для каждой ссылки:
    *   Загружается страница товара.
    *   При необходимости производится клик по кнопке раскрытия данных.
    *   Обновляется HTML страницы.
3.  Извлекаются данные (см. список выше).
4.  Данные сохраняются в таблицу `items`.
5.  Ссылка помечается как обработанная (`is_parsed = True`).

**Файл:** `parse_item_info.py`

## 📊 Какие данные парсятся (структура БД `items`)

Для каждого товара собираются следующие поля:

| Поле | Тип данных | Описание |
| :--- | :--- | :--- |
| `link` | TEXT | Ссылка на товар |
| `article` | TEXT | Артикул |
| `name` | TEXT | Название товара |
| `price` | REAL | Цена |
| `description` | TEXT | Описание |
| `images` | JSON | Список URL изображений |
| `characteristics` | JSON | Характеристики товара с сохранением структуры (ключ-значение) |
| `seller_name` | TEXT | Имя продавца |
| `seller_link` | TEXT | Ссылка на продавца |
| `sizes` | JSON | Доступные размеры |
| `rating` | REAL | Рейтинг товара |
| `reviews_count` | INTEGER | Количество отзывов |

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/your_username/wb_parser.git
cd wb_parser
```

### 2. Создание виртуального окружения (рекомендуется)
```bash
python -m venv venv
# Активация:
# Linux/macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
**Основные зависимости:** `selenium`, `beautifulsoup4`

### 4. Создание таблиц базы данных
Инициализирует БД, создавая таблицы `urls` и `items`.
```bash
python create_tables.py
```

### 5. Парсинг ссылок на товары
Собирает ссылки с поисковой выдачи и сохраняет их в БД.
```bash
python collect_urls.py
```
**Результат:** В таблице `urls` появятся ссылки с флагом `is_parsed = False`.

### 6. Парсинг данных о товарах
Обрабатывает все необработанные ссылки, собирая детальную информацию.
```bash
python collect_extended_info.py
```
**Результат:** Данные сохраняются в таблицу `items`, ссылки помечаются как обработанные (`is_parsed = True`).

---

### 7. Экспорт данных в XLSX

Для экспорта данных из базы данных в формат Excel используется скрипт `export_to_xlsx.py`.

**Функциональность:**

Скрипт выполняет следующие действия:
1. Подключается к базе данных SQLite
2. Извлекает все собранные данные о товарах
3. Преобразует JSON-данные (изображения, размеры, характеристики) в читаемый текстовый формат
4. Создает XLSX-файл с удобной структурой

**Использование скрипта:**

1. **Базовое использование (экспорт всех товаров)**
```bash
python get_xlsx.py
```
Создаст файл items.xlsx со всеми товарами из базы данных.

```bash
python get_xlsx.py 50
```
Экспортирует только первые 50 товаров.

2. **Экспорт с указанием имени файла**
```bash
python get_xlsx.py 100 "пальто_данные.xlsx"
```

3. **Экспорт всех с указанием имени**
```bash
python get_xlsx.py "" "пальто_данные.xlsx"
```

#### Аргументы командной строки:
Скрипт принимает два необязательных аргумента:
- limit (опционально) - максимальное количество товаров для экспорта
- filename (опционально) - имя выходного XLSX-файла (по умолчанию: items.xlsx)
